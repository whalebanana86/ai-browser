# TASK-013 X에서 번역 안 됨, 팔로우 추천 글자 사라짐, 한국어와 섞인 페이지에서 외국어만 번역

- 상태: COMPLETED (2026-11-12) — X 자체는 로그인이 필요해 직접 확인 못 함
- 요청: (X 스크린샷) "x에서 번역이 안되고 오른쪽 팔로우추천에도 번역되면서 글자가 안보여 그리고 이렇게 한글이랑 외국어가 섞여있는 경우도 외국어만 번역되게 수정해줘"
- 원인(코드로 판단):
  1. 번역 대상을 p·li·h1 같은 의미 태그로만 찾음. X 게시물 글은 `div`+`span`이라 대상이 아님.
  2. 언어 판단을 묶음(3블록) 단위로 함. X 화면은 한국어 UI가 많아 묶음이 "한국어"로 판정되어 외국어 게시물도 통째로 건너뜀.
  3. 팔로우 추천처럼 이름·핸들·버튼이 한 블록에 있으면 번역문을 한 글자 자리에 몰아넣고 나머지(버튼 글자 포함)를 비움.
## 요구사항
1. 블록은 태그가 아니라 레이아웃으로 찾는다: 글자 노드마다 가장 가까운 블록 상자(display가 inline/contents가 아닌 조상)가 그 글의 블록. 블록의 글은 그 블록에 직접 속한 글자만(안쪽 블록의 글 제외).
2. 버튼·입력·코드·편집 영역 안의 글은 건드리지 않는다.
3. 언어 판단은 블록마다: 이미 대상 언어인 블록(예: 한국어 대상이면 한글이 글자의 절반 이상)은 건너뛰고 외국어 블록만 번역.
## 완료 조건
- [x] AC1. 테스트: div+span 게시물 글이 한 블록으로 번역됨. 팔로우 추천 같은 칸에서 이름·핸들이 각자 블록, 버튼 글자는 그대로. 한국어 블록은 건너뛰고 같은 화면의 일본어·영어 블록만 번역.
- [x] AC2. 기존 테스트(숨김, 이미지, 색, 스크롤, 복원) 유지.
- [x] AC3. 실제 페이지(로그인 없이 열리는 곳)와 실제 모델로 확인, 깨뜨리면 실패, auto-fix-loop, 재설치.
