# TASK-011 번역할 때 이미지가 사라지고 글자색이 바뀌는 문제

- 상태: COMPLETED (2026-11-12)
- 요청: "https://edition.cnn.com/2026/11/10/media/trump-media-midterms-gop-takeaways 열어서 맨 하단으로 가면 번역하면서 이미지가 사라져 그리고 번역하면서 글자색을 바꾸지 않게 해"
- 원인: 번역을 넣을 때 블록의 자식 전체를 글자 노드 하나로 바꿈(`replaceChildren`) → 블록 안의 이미지(카드형 목록), 색을 입힌 span·링크가 사라져 글자색도 바뀜.

## 요구사항
1. 요소는 하나도 지우거나 바꾸지 않고 글자 노드의 내용만 바꾼다. 번역문은 블록 바로 아래 글자 노드 중 가장 긴 곳(없으면 가장 긴 글자 노드)에 넣고 나머지 글자 노드는 비운다.
2. 원문 보기는 각 글자 노드의 원래 내용을 되돌린다(노드는 그대로).
