## 요구사항
- 툴바에 다운로드 아이콘. 받는 동안 아이콘 둘레에 진행 고리(크기를 모르면 짧은 고리), 도움말에 "N개 받는 중 · %".
- 다운로드가 시작되면 사용 중인 창에서 다운로드 목록이 자동으로 열림(Safari·크롬처럼). 아이콘·보기 메뉴(⌥⌘L)로도 열고 닫음.
- 목록: 최신순, 파일 아이콘·이름·진행률/크기/실패/취소됨/"파일이 옮겨졌거나 삭제됨". 완료 파일 클릭 → 열기, 돋보기 → Finder에서 보기, 받는 중 → 취소. "다운로드 폴더 열기", "목록 지우기"(받는 중은 남김, 파일은 지우지 않음).
- 기록은 `~/Library/Application Support/Feather/downloads.json`에 최대 100개. 시크릿 탭 다운로드는 파일에 쓰지 않음(앱 종료 시 사라짐). 앱이 꺼질 때 받는 중이던 것은 다음 실행 때 "실패".
- 실패·취소 시 반쯤 받은 파일은 지움.
